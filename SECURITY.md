# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps:

1. **Do NOT open a public GitHub issue**.
2. Send an email describing the vulnerability to the project maintainers.
3. Include detailed steps or code samples to reproduce the issue.
4. We will respond within 48 hours to acknowledge receipt and work on a resolution.
